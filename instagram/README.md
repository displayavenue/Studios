# DisplayAvenue Instagram skills

13 Claude skills for @displayavenue, from [Jakeschincariol/instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) (MIT, see LICENSE).

Install in Claude Code:

    mkdir -p ~/.claude/skills ~/.claude/instagram
    cp -r instagram/skills/ig-* ~/.claude/skills/
    cp instagram/templates/voice.md ~/.claude/instagram/voice.md

Then fill in `voice.md`. Note: this repo is public, so keep private numbers and client details out of anything committed here.
