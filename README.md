# DisplayAvenue Studios

Premium website for **DisplayAvenue Studios** — India's Premium Visual Production Studio.

## Stack

- React 19 + TypeScript + Vite
- React Router
- Custom design system (Cormorant Garamond + Poppins, black / gold / white)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Pages

Home, About, Services (+ detail), Packages, Pricing, Portfolio (+ detail), Industries, Locations (+ detail), Blog (+ post), FAQs, Book Now, Contact.
