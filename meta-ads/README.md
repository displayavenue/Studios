# DisplayAvenue Meta Lead Ads Pack

Ready-to-upload creatives and a test plan for lead campaigns that drive **free-call bookings** for [displayavenue.com](https://displayavenue.com).

## Quick start

1. Open `preview/index.html` to review creatives.
2. In Meta Ads Manager → Create → **Leads** → Instant Form (see `INSTANT_FORM.md`).
3. Upload PNGs from `creatives/` and paste copy from `AD_COPY.md`.
4. Follow audience + kill/scale rules in `CAMPAIGN_BRIEF.md`.

## What’s included

| Asset | Purpose |
| --- | --- |
| 4 feed ads (1:1) | Pain, offer, proof, local angles |
| 3-card carousel | Get found → enquiries → know what works |
| 2 Stories/Reels (9:16) | Ads→calls + free call offer |
| Copy bank C1–C7 | Primary text, headlines, descriptions |
| Instant Form spec | Questions that filter for budget + intent |
| Campaign brief | Audiences, budget, UTMs, SLA |

Primary CTA everywhere: **Book a free call**.
